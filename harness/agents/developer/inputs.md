# developer — inputs

Lê:
- `src/**` — o código de negócio atual.
- `tests/unit/**` — os testes existentes.
- `docs/**`, `README.md` — contexto do negócio.
- `harness/prompts/*.md` — o template da tarefa que a harness lhe passa.

Não lê (não é seu escopo): `tests/qa/**`, `harness/schemas/**`, credenciais ou variáveis `WEBQA_*`.
