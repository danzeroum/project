# developer — outputs

- `src/**` — implementação do negócio.
- `tests/unit/**` — testes de unidade que acompanham a mudança.

Nunca escreve: `harness/**` (exceto quando explicitamente delegado), `tests/qa/**`,
`requirements-qa.txt`, nem qualquer arquivo do padrão (`webqa/`, `checks/`, `data/`).
